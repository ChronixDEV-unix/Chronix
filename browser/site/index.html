ABOUT THIS PREVIEW

What’s running?

  • CPU: emulated x86-64 PC
  • Kernel: Debian amd64 Linux
  • Desktop: Chronix JWM
  • Login: automatic for the browser preview
  • Storage: local virtual disk image
Preview limitations

CPU emulation is slower than a native install. This emulator currently uses one virtual CPU, supports up to 4 GB of guest RAM, and has no 3D acceleration. The first preview has no guest internet connection yet.

Disk changes

Changes are made to the in-memory copy of the selected disk. Use “Save disk image” before closing the tab to keep them.

Show virtual machine serial log 
Serial output will appear here when the VM starts.
Chronix is built on Debian. Browser emulation powered by v86_64. Third-party notices are included with the browser runtime.
